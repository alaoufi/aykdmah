# وكيل التطوير الخاص

تجمع اللوحة طلبات «أي خدمة» و«تربح» في واجهة عربية. لكل مشروع سجل وطابور مستقلان. يُحفظ الطلب ومعيار اختباره في قاعدة بيانات على الخادم. يعرض «متابعة المهام» ما إذا كان الطلب ينتظر العامل أو تسجيل الدخول أو التحقق من نتيجة التنفيذ.

## الاستخدام

1. سجّل الدخول من جهاز المالك، ثم اختر المشروع.
2. اكتب ما تريد إنجازه وكيف يمكن اختبار النتيجة. إذا غاب معيار القبول يُحفظ الطلب ويتيح زر المتابعة استكماله.
3. تُحفظ المحادثة على الخادم وتتحدّث في النوافذ المفتوحة كل خمس ثوانٍ. يستمر العامل مستقلًا بعد إغلاق المتصفح.
4. عند توقف طلب قبل بدء التنفيذ بسبب غياب تسجيل الدخول، أكمل دخول Codex ثم اضغط «متابعة بعد تفعيل الاشتراك». حالات الانقطاع أثناء التنفيذ تتطلب مراجعة نقطة التوقف.
5. للتنبيه عند انتهاء تشغيل أو توقفه، اضغط «تفعيل الإشعارات» واسمح للمتصفح. محتوى التنبيه عام. يتطلب وصوله اشتراك Push صالحًا من الجهاز.
6. من رابط الشبكة الخاصة، استخدم خيار التثبيت في Chrome أو Edge، أو المشاركة ثم «إضافة إلى الشاشة الرئيسية» في Safari على iPhone.

## الاشتراكات والصلاحيات

Codex هو المنفذ الأول. يجري تسجيل الدخول الرسمي بحساب ChatGPT من الطرفية الموثوقة للعامل. تبقى المهام التي يتعذر إرسالها محفوظة. عند استخدام Claude يدويًا يضغط المالك «نسخ ملخص لـ Claude Code» في متابعة المهام ثم يراجع النص وينقله إلى تطبيق Claude Code الرسمي بحسابه. يظل تفعيل Claude وإرسال أي نص إليه قرارًا مستقلًا. لا توجد مفاتيح فوترة للنماذج في الواجهة.

تُراجع نتيجة العامل واختباراتها قبل حفظ التعديل البرمجي في فرع مراجعة على GitHub. تبقى رسائل المهام خاصة. تُحتجز الطلبات الواضحة المتعلقة بالإنتاج أو DNS أو الدفع أو المتاجر للموافقة. يعتمد منع الآثار الخارجية كذلك على عزل أدوات التنفيذ وغياب مفاتيح النشر.

## التحقق والتشغيل

يلزم Node.js 22.13 أو أحدث. ثبّت تبعيات هذا المجلد بواسطة `npm ci --ignore-scripts` ثم نفّذ `npm test`. إعداد المتغيرات موضح في `.env.example`. تستمع خدمة الويب على loopback خلف HTTPS. يلزم أصل HTTPS مطابق، وكلمة مرور طويلة، ومفتاح جلسة مستقل. تحتفظ وحدة مصادقة خاصة ببيانات الجلسات والحدود ومفاتيح Web Push. يحتفظ SQLite بسجل المهام ويمنع إعادة معالجة طلب سبق تنفيذه تلقائيًا.

- دليل إعداد العامل ودخول الاشتراك واختبار العزل في [تشغيل العامل](ops/WORKER.md).
- دليل الخادم والشبكة واستعادة النسخ في [تشغيل الواجهة الخاصة](ops/PRIVATE_WEB.md).
- لتشغيل فحص المتصفح، ثبّت تبعيات جذر المشروع وشغّل `playwright install chromium` ثم `node tests/browser.cjs` من مجلد اللوحة مع توفر OpenSSL. يفتح الاختبار جلستين مستقلتين ويتحقق من الخصوصية والتزامن والواجهة العربية.
- تعليمات الاستئناف وتصدير تغييرات مهمة للمراجعة في [المهام الخلفية](BACKGROUND_JOBS.md).
- سجلات المشاريع والإصدارات وصلاحيات المتاجر في `projects.json` و`store-registry.json`. تجهيز مسارات التطبيقات لا يمنح إذنًا للنشر.
