# مركز الوكيل — جميع المشاريع (نسخة أولية غير منشورة)

واجهة عربية محادثية مستقلة، لا تغيّر الموقع الرئيسي. تبدأ بمشروعين: `alaoufi/aykdmah` و`alaoufi/Trbhh`؛ يمكن إضافة مشاريع أخرى إلى قائمة السماح في `server.cjs` بعد التحقق من صلاحياتها.

## ما أُنجز
- واجهة ويب RTL للجوال والكمبيوتر؛ محادثة طلبات متتابعة، اختيار المشروع، واختيار Claude أو Codex أو توجيه تلقائي.
- سجل رسائل منفصل حسب المشروع على خادم خاص.
- تسجيل كل طلب بوصفه GitHub Issue في مستودع المشروع إذا ضُبط `GITHUB_TOKEN` محدود الصلاحية.
- التوجيه الحالي **اقتراحي** وفق نوع الطلب وتكوين `AGENT_ENABLED_PROVIDERS`، ولا يتحقق من حالة جلسات Claude/Codex الفعلية.
- لا توجد اتصالات API فعلية بنماذج Claude أو Codex؛ لا يدّعي النظام تنفيذ المهام برمجيًا.

## تشغيل تجريبي محلي خلف HTTPS
يتطلب Node.js 22 أو أحدث. عيّن متغيرات البيئة `AGENT_CONSOLE_PASSWORD` (16 رمزًا فأكثر)، و`SESSION_SECRET` (32 رمزًا فأكثر). اختياريًا `GITHUB_TOKEN` بصلاحية Issues:write على المستودعات المعتمدة، و`AGENT_ENABLED_PROVIDERS=claude,codex` **فقط إذا كانت خدمات التنفيذ مهيأة فعلًا**.

```sh
cd agent-console
node server.cjs
```

الخدمة تستمع على `127.0.0.1:4318` فقط. يجب وضعها خلف reverse proxy مؤمّن بـ HTTPS وبصلاحيات وصول خاصة. لا تفتح المنفذ للعامة.

## شروط قبل الإنتاج
1. تدقيق الأمان: منع محاولات الدخول المتكررة، جلسات مستخدمين متعددة عند الحاجة، CSRF وحماية البيانات ونسخ احتياطية.
2. تكامل حقيقي بخدمات تنفيذ Claude وCodex مع تفويض مستقل، وضبط الميزانيات والأذونات.
3. عامل مهام غير متزامن وطابور تشغيل وتحديث الحالة في المحادثة، وWebhook مصادق عليه.
4. اختيار مزود متاح فعليًا عبر فحص حالة الاتصال والحدود قبل إسناد المهمة، لا الاعتماد على الكلمات المفتاحية.
5. اختبارات حقيقية للواجهة والخلفية وتسجيل النتائج؛ **لم تختبر هذه النسخة ولم تُنشر**.

الملفات في PR للمراجعة فقط. موافقة المالك مطلوبة قبل نشر لوحة الإدارة أو أي تعديل على بيئة الإنتاج.
