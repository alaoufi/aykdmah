استرجاع كود خدمات أوتاد من النسخة المنشورة

هذه الحزمة لا تتضمن الكود الكامل حاليًا. السكربت المرفق يسترجع ملفات المصدر التي رُفعت إلى نشر Vercel المعروف، بعد تسجيل الدخول إلى حساب Vercel المالك نفسه أو حساب مخول له.

الأفضل أولاً: إن كانت لديك نسخة أحدث من مجلد التطوير أو مستودع Git محدث، انقلها مع HANDOVER.txt وCOPY-TO-NEW-CHAT.txt؛ فهي قد تحتوي ملفات لم تُرفع إلى Vercel.

إذا لم توجد نسخة محلية، اطلب من الحساب الجديد تنفيذ الآتي:
1. تثبيت Node.js وPython 3 في بيئة العمل إن لم يكونا موجودين.
2. تثبيت أداة Vercel:
   npm install -g vercel@62.4.0
3. تسجيل الدخول إلى حساب Vercel الحالي:
   vercel login
   يتم الدخول في صفحة Vercel الرسمية؛ لا ترسل كلمة المرور أو الرموز السرية في المحادثة.
4. من مجلد هذه الحزمة، تشغيل:
   python3 export_published_source.py
   في بعض أجهزة Windows يكون الأمر python بدلاً من python3.

الناتج عند النجاح:
- مجلد AWTAD-published-source
- ملف AWTAD-published-source.zip
- بيان SOURCE-MANIFEST.json يذكر الملفات وفحوص سلامتها والاستثناءات.

ارفع ملف ZIP الناتج إلى الحساب الجديد مع ملف التسليم. يتوقف السكربت إذا كانت الاستجابة ناقصة أو الملف غير مطابق لمعرّف محتواه. يستخدم قراءات GET فقط ولا ينشر الموقع أو يغير الاستضافة أو قاعدة البيانات، ولا يستخرج أسرار البيئة أو بيانات العملاء. لا يستبدل ملفات موجودة مسبقًا؛ اختر أسماء جديدة عبر --output و--zip عند إعادة المحاولة.
