# توافق الأجهزة: الرسائل والتنبيهات والمكالمات

سجل حيّ لمشاكل كل نظام تشغيل ومتصفح وحلولها، يُحدَّث مع كل مشكلة جديدة. مصادره:
- **سجل الأجهزة وقدراتها** (`device_reports`، ترحيل 058). يظهر في لوحة الإدارة ← المكالمات ← «📱 الأجهزة وقدراتها».
- **سجل جودة المكالمات** (`call_diagnostics`، ترحيل 057). يظهر في نفس الصفحة ← «📶 سجل جودة المكالمات».
- سجل الخادم (`docker logs aykdmh-app`)، وسجل LiveKit (`docker logs aykdmh-livekit`).

## كيف تُدرس مشكلة جهاز
1. **من «الأجهزة وقدراتها»:**
   - النظام والمتصفح وإصدار الموقع.
   - هل التنبيهات ✅ مشتركة، ومن أي خادم تنبيهات.
   - أذونات الميكروفون والكاميرا، ودعم المكالمات.
2. **من «سجل جودة المكالمات»:**
   - المسار: `udp` مباشر، أو `relay-tls` عبر 443.
   - التأخير، وفقد الحزم، والصوت الواصل، ومنع المتصفح للصوت.
3. **رفض اشتراك التنبيهات:** يظهر في سجل الخادم كسطر `Push subscription rejected: host=…`.

## ما نعرفه حتى الآن

| النظام / المتصفح | المشكلة | الحل | الحالة |
|---|---|---|---|
| أندرويد + Chrome | خادم تنبيهات `jmt17.google.com` كان يُرفض، فلا يصل أي تنبيه (2026-10-30) | أُضيف للقائمة الموثوقة في `server/services/pushService.js` مع `android.googleapis.com` | محلولة |
| أندرويد + Chrome | يمنع تشغيل صوت الطرف الآخر تلقائيًا، فتتصل المكالمة بلا صوت | `room.startAudio()` فور الاتصال، وزر «🔊 اضغط هنا لسماع الصوت» عند المنع (`AudioPlaybackStatusChanged`) | محلولة، تنتظر تجربة |
| أندرويد | التنبيه بنغمة النظام، ولا يظهر فوق البرامج إلا بإعداد | الإعدادات ← التطبيقات ← Chrome ← الإشعارات ← المواقع ← aykdmh.com: «الظهور على الشاشة» ونغمة مميزة. الخطوات داخل «ملفي» مع «🔔 جرّب التنبيه» | إرشاد |
| أندرويد (معظم الأجهزة) | لا يسمح للمواقع باختيار سماعة المكالمة (earpiece) | زر السماعة يبدّل المخارج إن أتاحها المتصفح، وإلا تلميح: السماعة السلكية أو البلوتوث تتحول تلقائيًا | قيد المتصفح |
| آيفون / آيباد (Safari) | لا تنبيهات للمواقع إلا بعد «إضافة إلى الشاشة الرئيسية» وفتحه من الأيقونة (iOS 16.4 فأحدث) | تحذير وخطوات آيفون تظهر تلقائيًا في «ملفي» | إرشاد |
| آيفون | خادم التنبيهات `web.push.apple.com` | مقبول منذ AYK-008 | يعمل |
| هواوي بلا خدمات Google | Chrome لا يستطيع الاشتراك في التنبيهات | رسالة `push.no_service`؛ البديل: إبقاء الموقع مفتوحًا، أو تطبيق أصلي لاحقًا | قيد الجهاز |
| كل الأنظمة | الاتصال الفوري كان يتوقف بعد 8 محاولات حتى إعادة تحميل الصفحة | محاولات بلا حد، وإعادة اتصال عند العودة للشاشة، وفحص كل 15 ثانية وقت الانقطاع | محلولة |
| كل الأنظمة | منافذ المكالمات محجوبة قبل الخادم | TURN عبر 443 خلف Caddy (layer4)، ثم صار UDP 7882 يصل مباشرة | محلولة |

## حدود المواقع مقارنة بالتطبيقات
- **شاشة مكالمة فوق كل البرامج، ونغمة رنين خاصة والموقع مغلق:** تحتاج تطبيقًا أصليًا. البديل الحالي: إشعار المكالمة فيه «📞 رد» و«رفض»، ويبقى ظاهرًا حتى يُتعامل معه.
- **مستوى الصوت:** نغمات الموقع تتبع صوت الوسائط في الجوال، وتنبيه الموقع المغلق يتبع صوت الإشعارات.
