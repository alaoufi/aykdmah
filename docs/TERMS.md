# مصطلحات «أي خدمة» الموحّدة (AYK-373)

قرار المالك (2026-11-21): «وحّد جميع المصطلحات في جميع التطبيق حتى الإدارة». أي نص جديد يلتزم بهذا الجدول.

| المعنى | المصطلح | لا يُستعمل |
|---|---|---|
| من يطلب الخدمة | طالب الخدمة (الجمع: طالبو / طالبي الخدمة) | العميل، عميل، العملاء، صاحب الطلب، الزبون |
| من يقدّم الخدمة | مقدم الخدمة (الجمع: مقدمو / مقدمي الخدمة) | الفني، المزوّد («الدعم الفني» اسم القسم فقط) |
| نوع العمل | المهنة / المهن | التصنيف، التصنيفات، القسم |
| صفحة الشخص نفسه | حسابي | ملفي، ملفي الشخصي، لوحة التحكم |
| صفحة الإدارة | لوحة الإدارة | لوحة التحكم |
| رقم الشخص | رقم الحساب (أعلى القائمة: «رقمك») | رقم العميل |
| تبويبات طالب الخدمة | طلباتي النشطة / أرشيف طلباتي | النشطة / الأرشيف وحدها |
| تبويبات مقدم الخدمة | أعمالي النشطة / أرشيف أعمالي | النشطة / الأرشيف وحدها |
| صفحة أعمال مقدم الخدمة | أعمالي | مهامي المهنية |
| إعدادات المهن والتغطية والأوقات | إعدادات عملي | شغلي |
| حالة الطلب | مفتوح، تم اختيار مقدم خدمة، قيد التنفيذ، مكتمل، ملغى | تم التعيين |
| حالة مقدم الخدمة | متاح للعمل (حسب جدوله)، متواجد (التطبيق مفتوح الآن) | متواجد بمعنى متاح |
| الدعوة | دعوة للانضمام | دعوة وحدها |
| عنوان فلتر اللوحة (AYK-444) | اعرض لي | عرض، فلتر |
| فلتر مقدم الخدمة (AYK-440) | مهنتي | تخصصي |
| فلتر طالب الخدمة (AYK-446) | مشابه لطلبي (طلب واحد) / مشابه لطلباتي (أكثر) | طلبي، حسب طلبي |
| فلتر المكان (AYK-440) | منطقتي | نطاقي، حيي |
| اختيار من لم يطلب بعد (AYK-447) | اختر ما تحتاجه من المهن | الأقسام |
| الطلبات المتفق عليها (AYK-441) | تم مؤخرًا (المهنة، المدينة، وقت الاتفاق) | الطلبات المنتهية |
| مفتاح الإدارة (AYK-440) | تقييد العرض حسب المهنة والمنطقة | فك القيود |

اللغات الأخرى: العناوين نفسها مترجمة لكل لغة (حسابي، المهنة، التبويبات). جمل الشرح في اللغات الأخرى صحيحة المعنى، ولم تُعد صياغتها كلمةً كلمة.
