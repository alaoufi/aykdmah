# AYK-174 — مراجعة الرئيسية

طلب المالك تدرجات خفيفة للأدوار وخلفية القالب، تقليل حجم أحدث الطلبات وفلتر خدمة وإصلاح زر الاستعراض، ثم النشر وإرسال APK. لا تغييرات بيانات أو محرك اتصال.

- `tone-provider` أزرق و`tone-request` برتقالي من ألوان الشعار، مستقلان عن تبديل القالب؛ سطح التدرج يتبع السطح الفاتح/الداكن. التباين العالي يحتفظ بسطح صافٍ وحد واضح.
- إزالة الهامش السالب من قسم التصنيفات الذي كان يقترب من نهاية قسم الخدمات، وسهم SVG لا ينكمش داخل رابط الاستعراض.
- Latest يستعلم حسب category_id من الخادم، مع حماية الاستجابات المتأخرة وتفسير الخطأ على الفلتر بالأحمر؛ لم يعد يصفّي أول 12 طلبًا فقط. دمج الموقع والتفاصيل، تقليل الحشو وتكرار العنوان، دون تغيير فتح الطلب أو الاتصال.
- دليل الاستخدام يتضمن شرحًا بكل اللغات الـ11. لا نوافذ متصفح مضافة.
- `scripts/review-home-174.cjs`: خادم ملفات محلي داخل حاوية معزولة بلا شبكة خارجية؛ كل بيانات API تجريبية. Chromium وWebKit: **90/90**، أحجام 360/390/768/1280، ar/en، خط xl، قوالب متعددة وداكن وتباين عالٍ؛ فلتر يجلب طلبًا خارج الصفحة الأولى، سباق استعلامين، فشل واستعادة، وعدم overflow أو أخطاء تشغيل. الصور من بيانات التجربة فقط.
- preflight-suite.txt: خادم 28/28، واجهة 121/121، تكامل 226/226، 11 لغة/2255 مفتاحًا حينها، بناء 38.77s وتدقيق وفحوص نشر. أُكملت بعدها ألوان الأدوار المستقلة عن القوالب ودليل 11 لغة (2256 مفتاحًا)؛ البناء النهائي والمتصفحات ناجحان، والفحوص الكاملة النهائية عبر testdeploy قبل التحويل.
- لا اختبار على هاتف مادي ضمن هذه المراجعة؛ لا ادعاء بإصلاح جودة الصوت. حزمة 1.3.4 (14) الموقعة الحالية تعرض تحديثات الويب بعد نشرها؛ لا حاجة لتغيير المحرك الأصلي لهذه الدفعة.
