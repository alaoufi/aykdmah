# مرفقات المستخدمين في Cloudflare R2 (AYK-248)

قرار المالك (2026-11-17):
- **المكالمات المباشرة**، صوتية أو مرئية، تمر فقط ولا تُحفظ. هذا هو الوضع أصلًا: `callService` يمنع التسجيل.
- **مرفقات المحادثات والطلبات**، من صور ورسائل صوتية ومقاطع مسجلة ومقاطع فيديو وملفات، تُحفظ في **مخزن R2 خاص**
  `aykdmh-media`، **ولا تُحفظ على الخادم إطلاقًا**: لا على القرص ولا في قاعدة البيانات. على الخادم يبقى الكود
  وقاعدة البيانات فقط.

## التصميم
- **جدول `uploaded_media`** يبقى كما هو: المالك، والنطاق، وقواعد الوصول، والاسم، والنوع، والحجم.
  - **ملف R2:** `storage = 'r2'`، والبايتات في `object_key`، و`data = NULL`.
  - **ملف قديم:** `storage = 'db'` حتى يُنقل.
- **الحفظ:** الملف يُفحص من الذاكرة (نوعه الحقيقي من بايتاته)، ثم يُرفع إلى R2، ثم يُسجل الصف.
  - إن فشل الرفع فلا يُحفظ شيء.
  - إن فشل التسجيل يُحذف الكائن من R2.
- **العرض:** `GET /api/media/:id` يمر بنفس فحص الصلاحية، ثم يحوّل (302) إلى **رابط موقّع صالح 5 دقائق**.
  - البايتات لا تمر بالخادم.
  - R2 يخدم مقاطع الصوت والفيديو بأجزاء (Range).
- **التوقيع:** AWS Signature V4 مكتوب في `server/services/objectStorage.js` بلا مكتبات خارجية، ويطابق أمثلة AWS الرسمية.
- **المفتاح:** Object Read & Write على `aykdmh-media` فقط، **بلا مرشح عناوين**، لأن روابط التنزيل تفتحها أجهزة
  المستخدمين. مفتاح النسخ الاحتياطية وحده المقيد بعنوان الخادم.
- **بلا إعداد** `R2_MEDIA_*`: تبقى الملفات في قاعدة البيانات كما كانت (للتطوير والاختبار).

## حدود الحجم (قابلة للتعديل من الإدارة ← الإعدادات ← الملفات)
| النوع | الحد | الإعداد |
|---|---|---|
| مقطع فيديو | 3 دقائق، 100 ميجابايت | `media_video_max_seconds`، `media_video_max_mb` |
| رسالة صوتية مسجلة | 10 دقائق، 20 ميجابايت | `media_voice_max_seconds`، `media_voice_max_mb` |
| صورة | 10 ميجابايت | `media_image_max_mb` |
| ملف أو مستند | 20 ميجابايت | `media_file_max_mb` |

### كيف يعمل الرفع المباشر
1. **الجهاز يطلب تذكرة رفع:** `POST /api/media/uploads { conversation_id, file_name, type, size, duration_seconds? }`.
   - **الخادم يتحقق:** المرسل طرف في المحادثة ويستطيع الإرسال، والنوع مسموح، والامتداد يطابقه، والحجم والمدة ضمن حدود الإعدادات.
   - **ثم:** يسجل صفًا `pending`، ويعطي رابط PUT لمدة 15 دقيقة، موقّعًا بالنوع والحجم بالضبط.
2. **الجهاز يرفع مباشرة إلى R2.** R2 يرفض أي حجم أو نوع غير الموقّع.
3. **الرسالة تُرسل بـ `media_ids`.** الخادم يفحص الحجم في R2 وأول البايتات (توقيع الصيغة)، ثم يجعله `ready`.
   - الملف المتنكر يُحذف من R2 ومن القاعدة.
4. **التذاكر غير المستخدمة** تُحذف بعد ساعتين مع كائناتها.
5. **بلا R2** (`/api/media/limits` تعيد `direct: false`): يبقى الرفع القديم عبر الخادم بحد 3.5MB.

## ما يحتاجه المالك عند النشر (ليس الآن)
1. **في Cloudflare:** R2، ثم **Create bucket** باسم `aykdmh-media`.
2. **مفتاح API:** Create Account API token
   - الاسم: `aykdmh-media-server`
   - الصلاحية: **Object Read & Write**
   - المخزن: `aykdmh-media` فقط
   - المدة: TTL Forever
   - **Client IP Filtering: فارغ** (بلا قيد عنوان)
3. **CORS على المخزن** (R2، ثم `aykdmh-media`، ثم Settings، ثم CORS Policy، ثم Edit):
   ```json
   [{"AllowedOrigins": ["https://aykdmh.com", "https://www.aykdmh.com"],
     "AllowedMethods": ["PUT", "GET", "HEAD"], "AllowedHeaders": ["Content-Type"], "MaxAgeSeconds": 3600}]
   ```
4. **على الخادم في `.env`:** `R2_MEDIA_ENDPOINT` و`R2_MEDIA_BUCKET=aykdmh-media` و`R2_MEDIA_ACCESS_KEY_ID`
   و`R2_MEDIA_SECRET_ACCESS_KEY`. تُدخل على الخادم فقط، ثم يُنشر.
5. **بعد التجربة على جوال**، وبموافقة المالك: `docker exec aykdmh-app node server/scripts/media-to-r2.js` (تقرير)،
   ثم `--apply`.
