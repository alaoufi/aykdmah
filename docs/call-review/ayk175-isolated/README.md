# تحقق المكالمات المعزول — AYK-175

النتيجة الفعلية **31/31**، وخروج المتصفح والحاضنة **0**. المصدر من `/tmp/ayk175-verified` بعد نجاح حزمة الاختبار الكاملة؛ بصمات الملفات في `verification.json`.

استخدم الاختبار سياقي Chromium مستقلين بميكروفون وكاميرا اصطناعيين، وقاعدة PostgreSQL وتطبيقًا وLiveKit 1.13.9 داخل شبكة Docker جديدة `--internal`، بلا منافذ منشورة على المضيف. أُنشئت مفاتيح LiveKit وJWT عشوائيًا وقت التشغيل؛ لم يُقرأ ملف بيئة إنتاج أو تُستخدم شبكة الإنتاج أو SFU الإنتاج. حُذفت الحاويات والشبكة وملفات الاعتماد المولدة بعد الاختبار.

أثبت الاختبار الصوت المفكوك الترميز غير الصامت للطرفين، وغياب طلبات التقاط الكاميرا أثناء الرنين وبعد الانضمام حتى التفعيل الصريح، ثم وصول الفيديو للطرفين. وبعد إغلاق كاميرا مقدم الخدمة وقطع شبكة حاوية SFU الخاصة 18 ثانية، أنشأ الطرفان اتصالَي signaling جديدين وعاد الصوت المفكوك الترميز، وبقيت الكاميرا مغلقة دون طلب التقاط جديد. شمل كذلك الكتم والرفض والإنهاء ورفض الطرف الخارجي HTTP 404.

بُنيت الواجهة المؤقتة بوضع `socket` المطابق لـ`deploy/setup-server.sh`. محاولة الإعداد الأولى استخدمت بناء CI ذي وضع `polling`؛ أنهت سياسة عدم إمكانية الوصول المكالمة قبل دورة الاستقصاء، لذلك استُبدل إعداد الاختبار بوضع الإنتاج وانتُظر اتصال Socket.IO المصادق للطرفين. لم تُعطّل سياسة الوصول ولم تُزرع أجهزة إشعارات وهمية.

## إعادة الإنتاج

الملف `harness-used.sh` هو الحاضنة الفعلية التي أعطت النتيجة، و`seed-used.cjs` و`adapt-used.cjs` مساعداها بلا مفاتيح مخزنة. على مضيف Docker مخصص للاختبار، جهّز نسخة المصدر المتحقق منها في `/tmp/ayk175-verified` وملف الخروج `/tmp/ayk175-verified-suite.exit` بقيمة 0 من تشغيل الحزمة، ثم انسخ المساعدات بأسمائها التي تتوقعها الحاضنة:

المتطلبات السابقة هي نسخة Linux مع `node_modules` الناتجة عن الحزمة، وبناء `client/dist` فيها، وصور Docker المخزنة `node:22-bookworm` و`postgres:16-alpine` و`livekit/livekit-server:v1.13.9` و`mcr.microsoft.com/playwright:v1.63.0-noble`. الحاضنة ليست مثبتًا لهذه المتطلبات؛ البناء يعمل بلا شبكة ولا ينزّل تبعيات.

```bash
cp harness-used.sh /tmp/ayk175-isolated-calls.sh
cp seed-used.cjs /tmp/ayk175-calls-seed.cjs
cp adapt-used.cjs /tmp/ayk175-calls-runtime-adapt.cjs
bash /tmp/ayk175-isolated-calls.sh
```

الحاضنة ترفض وجود `.env` أو `.env.local` في مصدر الاختبار، وتعيد بناء الواجهة مؤقتًا، وتولد أسماء جديدة تبدأ بـ`ayk175-calls-` وتزيل حاويات وشبكة ذلك التشغيل وحده. تترك مجلد العمل الخاص لجمع الأدلة؛ في التشغيل المسجل حُذفت منه ملفات الاعتماد الأربعة بعد فحص قائمة الملفات المسموح بتصديرها. لا تشغّل `deploy/e2e-calls.sh` لهذا التحقق؛ فهو يقرأ بيئة وشبكة وSFU الإنتاج. نسخة اختبار المتصفح الناتجة محفوظة أيضًا في `e2e/calls-isolated.e2e.mjs`؛ تعديلها بعد التشغيل اقتصر على هذه الإرشادات التعريفية.

## حدود النتيجة

هذه وسائط متصفح اصطناعية وليست تجربة هاتف مادي أو إثبات جودة المكبر أو التقطيع على الهاتفين. لم يشمل الاختبار TURN أو الشبكة العامة أو مقارنة السعودية، ولم تُفعّل Webhooks الخاصة بـLiveKit في هذه الشبكة. الأدلة المرفقة محصورة في النتائج وsignaling بلا query tokens وسجل قطع الشبكة؛ استُبعدت البيئة والمفاتيح وملفات seed المشتملة على الرموز وSDP الخام.
