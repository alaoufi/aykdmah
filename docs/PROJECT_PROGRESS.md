## طريقة النشر على الخادم

- المستودع منسوخ في `/opt/aykdmh` (فرع `claude/deploy-setup`).
- حاوية `aykdmh-web` (Caddy 2.8.4) تعمل على 80/443، والإعداد في `deploy/docker-compose.yml` و`deploy/caddy/Caddyfile`.
- الملفات المنشورة في `/var/www/aykdmh/releases/<stamp>`، والرابط `current` يشير إلى الإصدار الفعّال.
- التحديث: `cd /opt/aykdmh && git pull && bash deploy/setup-server.sh`.
- الرجوع: `ln -sfn releases/<older> /var/www/aykdmh/current`.
- الإزالة الكاملة: `docker compose -p aykdmh -f /opt/aykdmh/deploy/docker-compose.yml down`.
