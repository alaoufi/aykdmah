## طريقة النشر على الخادم

- المستودع في `/opt/aykdmh` (فرع `claude/deploy-setup`)، والأسرار في `/opt/aykdmh/.env` (صلاحية 600، ولا تُرفع إلى Git). نسخة منها في `/root/backups/`.
- الحاويات: `aykdmh-web` (Caddy)، و`aykdmh-app` (API بـ Node 22)، و`aykdmh-db` (PostgreSQL 16).
- التحديث: `cd /opt/aykdmh && git pull && bash deploy/setup-server.sh`. يأخذ السكربت نسخة احتياطية من القاعدة، ويبني الواجهة في إصدار جديد، ويطبق الترحيلات.
- الرجوع للواجهة السابقة: `ln -sfn releases/<older> /var/www/aykdmh/current`.
- استعادة القاعدة: `docker exec -i aykdmh-db pg_restore -U aykdmh -d aykdmh --clean < /root/backups/aykdmh-db-<stamp>.dump`.

## المنجز في هذه المرحلة

- دمج كود Codex المسترجع في فرع Claude.
- إصلاح 3 ثغرات معروفة: body-parser وmulter وnodemailer (تحديثات ضمن نفس الإصدار الرئيسي).
- `server/app.js`: الثقة بالبروكسي عند `TRUST_PROXY=1`، حتى يُحسب حد الطلبات لكل زائر لا للبروكسي.
- اختبارات الأمان في `security-uploads.integration.js` كانت تفشل لأن النسخة القديمة `7f4ec4b` غير موجودة. أصبحت تتخطى المقارنة بها فقط، وتفحص الكود الحالي كاملًا.
- نشر التطبيق الكامل بدل الصفحة المؤقتة.

## المتبقي

1. **حساب المدير:** لم يُنشأ. يحتاج بريدًا وكلمة مرور يختارهما المالك.
2. **الاسم والهوية:** الموقع يظهر باسم «خدمات أوتاد». تغييره إلى «أي خدمة» يحتاج قرار المالك.
3. **الوقت الفوري:** يعمل الآن بالاستقصاء (polling) كما كان على Vercel. يمكن تفعيل WebSocket لأن الخادم الآن دائم.
4. **SMS والبريد والدفع:** غير مفعّلة. لا يُفعّل الدفع الحقيقي قبل الاختبارات والموافقة.
5. **نسخ احتياطي دوري:** النسخ الحالي يحدث عند كل نشر فقط، ويحتاج جدولة يومية.
6. **اختبارات المتصفح (e2e):** مفقودة من الكود المسترجع.
7. **حجم الحزمة الرئيسية:** نحو 750KB، ويُنصح بتقسيمها لتحسين السرعة.
8. الوظائف المطلوبة لاحقًا: المكالمات الصوتية والمرئية المباشرة (الموجود حاليًا رسائل صوت وفيديو مسجلة)، والإشعارات، وتحسين لوحة الإدارة.
