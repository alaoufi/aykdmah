# تقدّم مشروع «أي خدمة»

آخر تحديث: 27 أكتوبر 2026 — فرع `claude/deploy-setup`

## الحالة على https://aykdmh.com

| الميزة | الحالة | نتيجة الاختبار |
|---|---|---|
| الموقع والهوية «أي خدمة» | يعمل | الشعار والأيقونات والعناوين واللغات الخمس، ولا أثر للأسماء القديمة في الكود |
| قاعدة البيانات | جديدة ونظيفة (بداية من الصفر) | حساب مدير واحد فقط، ونسخة احتياطية قبل الحذف في `/root/backups/` |
| الخرائط (Leaflet + OpenFreeMap) | يعمل | فحص يدوي على الجوال والكمبيوتر |
| تحديد الموقع وحفظه واستعادته | يعمل | اختبار تكامل: حفظ ثم إعادة القراءة من القاعدة |
| البحث عن العناوين | يعمل | نتائج حقيقية من OpenStreetMap (مثل عنيزة) |
| مقدمو الخدمة القريبون | يعمل | خصوصية الموقع، والمسافة، والترتيب، والتصفية: اختبار تكامل |
| المكالمات الصوتية | يعمل | اختبار حقيقي بين متصفحين: كل طرف يسمع الآخر، كتم، إنهاء، رفض |
| مكالمات الفيديو | يعمل | اختبار حقيقي: كل طرف يرى الآخر، إيقاف الكاميرا |
| صلاحيات الاتصال | يعمل | مستخدم ثالث يُرفض (404)، ورمز الدخول 15 دقيقة فقط |
| استمرار المكالمة بعد انقطاع الشبكة | غير مكتمل | فحص الانقطاع 4 ثوانٍ لم ينجح بعد |
| لوحة الإدارة للمكالمات | يعمل | `/admin/calls` |
| كلمة المرور | 4 خانات حد أدنى، وتغيير إلزامي عند أول دخول | مختبر على حساب المدير |

## الاختبارات (آخر تشغيل)

خادم 13/13، واجهة 116/116، تكامل 186/186، ترجمات 1352 مفتاحًا × 5 لغات، صفر ثغرات، بناء ناجح، فحوص النشر ناجحة.

## الخدمات المستخدمة وتكلفتها

كلها مجانية ومفتوحة المصدر: LiveKit (على الخادم)، OpenFreeMap، OpenStreetMap/Nominatim، Let's Encrypt. **لا تكاليف إضافية.**

## المتبقي

1. استمرار المكالمة بعد انقطاع الشبكة.
2. إشعارات Web Push للمكالمات عندما يكون التطبيق مغلقًا.
3. TURN عبر TLS للشبكات المقيدة جدًا (يحتاج نطاقًا فرعيًا مثل `turn.aykdmh.com`).
4. النظام الجغرافي الشامل للمملكة (المناطق والمحافظات والمدن والأحياء). مطلوب ولم يبدأ.
5. نسخ احتياطي يومي مجدول لقاعدة البيانات.
6. رفع حد استقبال UDP في نظام الخادم لأداء أفضل للمكالمات (تحذير من LiveKit).

## ما يحتاجه المالك

- تغيير كلمة مرور الإدارة عند أول دخول (يطلبها الموقع تلقائيًا).
- كلمة مرور root للخادم ظهرت في لقطة شاشة سابقًا، ويجب تغييرها من لوحة Contabo.
